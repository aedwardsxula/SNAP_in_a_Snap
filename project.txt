HOW TO HIDE YOUR API KEY
* Create a .env file
* create a variable to hold it e.g “API_KEY = 1JSNUN9EI0HFC0I”
* Add the filename “.env” to gitignore file to prevent git from tracking the file.
* Ensure to never push .env file to github !
